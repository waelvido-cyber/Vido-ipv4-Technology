# VIDO IPv4 & Network Lab V10

Foundation release based on the existing VIDO IPv4 trainer. Includes navigation/history, multilingual UI (DE/EN/AR), question IDs, notes, search, progressive help, video-learning placeholders, mastery/error tracking, exam timer, and an interactive network-simulator foundation with PC/Switch/Router, IPv4 configuration and basic ping/subnet validation.

This is an original learning tool; it does not contain original copyrighted IHK exam questions.
